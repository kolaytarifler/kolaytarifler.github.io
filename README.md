# Kolay Tarifler

Türkçe statik site: ücretsiz mutfak araçları (tarif ölçekleyici, birim dönüştürücü, kalori hesaplayıcı, malzeme ikame bulucu, alışveriş listeli yemek planlayıcı), dönüşüm tabloları ve altı mutfak rehberi.

Teknolojiler: yalnızca HTML, CSS ve vanilla JavaScript; harici kütüphane yok.

Barındırma: GitHub Pages — https://kolaytarifler.github.io/
